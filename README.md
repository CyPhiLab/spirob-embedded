# Spirob Embedded Resistive Sensor
This project implements resistance-based proprioceptive sensing for SpiRob, a cable-driven hyper-redundant robot.


### Assembly
#### Parts (per-joint)
- 8 m2 threaded inserts
- 4 strips of piezoresistive silicon (sized according to corresponding joint)
- wires (ideally 32-36 awg)
- 8 m2x4mm screws

#### Proccess
1) instert threaded inserts into holes in the half segments
2) poke hole into each end of each segment
3) push screw through each hole
4) screw each screw into the correct threaded insert
5) wrap 1 wire around each screw meant for voltage
6) wrap 1 wire around all screws meant for ground and feed it through the joint to it comes out the same side and the rest of the wires

### Project Goal
Develop and characterize an embedded sensing system for estimating SpiRob's deformation and supporting future proprioceptive control and digital-twin integration.
